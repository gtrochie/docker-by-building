# Module 06 — Solutions

**1. DB (unpublished) + API (published) on one network; db/ping ok.**
```bash
docker network create forge-net
docker run -d --name db --network forge-net \
  -e POSTGRES_USER=forge -e POSTGRES_PASSWORD=forge -e POSTGRES_DB=freelanceforge \
  postgres:16-alpine
docker run -d --name api --network forge-net -p 8000:8000 \
  -e DATABASE_URL=postgresql://forge:forge@db:5432/freelanceforge freelanceforge:dev
curl localhost:8000/db/ping        # {"db":"ok","version":"PostgreSQL 16..."}
```

**2. From inside the API, prove name resolves + port open.**
```bash
docker exec api getent hosts db                 # prints an IP for 'db'
docker exec api sh -c 'nc -z db 5432 && echo reachable'
```

**3. Reproduce and fix "could not translate host name".**
```bash
docker run -d --name db2 -e POSTGRES_PASSWORD=x postgres:16-alpine      # default bridge
docker run -d --name api2 -p 8001:8000 \
  -e DATABASE_URL=postgresql://forge:forge@db2:5432/freelanceforge freelanceforge:dev
curl localhost:8001/db/ping        # {"db":"error","detail":"could not translate host name..."}
# fix: put them on a shared network
docker network connect forge-net db2
docker network connect forge-net api2
curl localhost:8001/db/ping        # now resolves
```
