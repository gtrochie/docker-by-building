# Module 09 — Solutions

**1. Compare dev vs prod image sizes.**
```bash
docker build -t freelanceforge:dev .
docker build -f dockerfiles/Dockerfile.multistage -t freelanceforge:prod .
docker images freelanceforge
```
`prod` is smaller (or equal for tiny deps) because build tooling/caches from the
builder stage never reach the final image — only the venv + source are copied.

**2. Prove non-root + no compiler.**
```bash
docker run --rm freelanceforge:prod whoami                       # appuser
docker run --rm freelanceforge:prod sh -c 'command -v gcc || echo none'   # none
```

**3. Alpine runtime base.**
```dockerfile
FROM python:3.12-alpine AS runtime
```
```bash
docker build -f dockerfiles/Dockerfile.multistage -t freelanceforge:alpine .
docker images freelanceforge:alpine     # typically smaller
```
Note: Alpine uses musl libc; some Python packages need a wheel or build deps
(`apk add build-base`) — `-slim` avoids that at a modest size cost.
