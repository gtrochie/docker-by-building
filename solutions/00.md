# Module 00 — Solutions

**1. Run hello-world, then remove the stopped container.**
```bash
docker run hello-world
docker ps -a                         # find it (status: Exited)
docker rm <container-id-or-name>     # remove by the ID/name shown
# or in one go: docker rm $(docker ps -aq --filter ancestor=hello-world)
```

**2. nginx detached on host port 9000, confirm, then logs.**
```bash
docker run -d -p 9000:80 --name web nginx:alpine
curl -s localhost:9000 | head -1     # <!DOCTYPE html> ...
docker logs web
docker rm -f web
```

**3. One-sentence definitions.**
- *Image vs container:* an image is a read-only template (a class); a container is
  a running instance of it (an object).
- *Daemon vs client:* the daemon (`dockerd`) is the engine that builds images and
  runs containers; the `docker` CLI is a client that sends it commands.
