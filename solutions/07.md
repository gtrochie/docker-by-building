# Module 07 — Solutions

**1. Same image, three VAT rates.**
```bash
for r in 0.0 0.15 0.20; do
  docker run --rm -d -p 8000:8000 -e VAT_RATE=$r --name ff freelanceforge:dev
  sleep 1; curl -s localhost:8000/ ; echo; docker rm -f ff
done
# vat_rate reflects 0.0 / 0.15 / 0.2 — no rebuild between runs
```

**2. Config via --env-file.**
```bash
cat > forge.env <<ENV
APP_ENV=production
VAT_RATE=0.15
DATABASE_URL=postgresql://forge:forge@db:5432/freelanceforge
ENV
docker run --rm -p 8000:8000 --env-file forge.env freelanceforge:dev
grep -q '.env' .dockerignore && echo ".env ignored ✓"
```

**3. Demonstrate the secret leak, then do it right.**
```bash
# BAD: bake it
#   ENV DEMO_SECRET=leak-me   -> in the Dockerfile
docker history --no-trunc freelanceforge:leaky | grep DEMO_SECRET   # visible!
docker run --rm freelanceforge:leaky printenv DEMO_SECRET           # leak-me
# GOOD: pass at run time, never in the image
docker run --rm -e DEMO_SECRET=leak-me freelanceforge:dev printenv DEMO_SECRET
```
