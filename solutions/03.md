# Module 03 — Solutions

**1. Install curl correctly in a single RUN; lint clean.**
```dockerfile
RUN apt-get update && apt-get install -y --no-install-recommends curl \
    && rm -rf /var/lib/apt/lists/*
```
`hadolint Dockerfile` reports no findings for this line: one layer, no-recommends,
lists cleaned.

**2. Dev CMD with --reload, overridden at run time without rebuild.**
```dockerfile
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000", "--reload"]
```
Override per run (no rebuild) by appending a command:
```bash
docker run --rm freelanceforge:dev uvicorn main:app --host 0.0.0.0 --port 8000
```

**3. Clean rewrite of the bad Dockerfile.**
```dockerfile
# syntax=docker/dockerfile:1
FROM python:3.12-slim
ENV PYTHONUNBUFFERED=1 PYTHONDONTWRITEBYTECODE=1
WORKDIR /app
COPY app/requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY app/ .
EXPOSE 8000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```
`hadolint` → no output (clean). Fixes: pinned tag, COPY not ADD, single cached
install, no pip cache, exec-form CMD.
