# Module 02 — Solutions

**1. Restart policy brings a killed container back.**
```bash
docker run -d --restart unless-stopped -p 8080:80 --name web nginx:alpine
docker kill web             # kills the main process
docker ps                   # within a second it's Up again (restart policy)
docker rm -f web
```

**2. Long-lived python container; version two ways.**
```bash
docker run -d --name py python:3.12-slim sleep 3600
docker exec py python3 --version           # single command
docker exec -it py sh                        # interactive: then run python3 --version, exit
docker rm -f py
```

**3. Container that exits immediately — explain why.**
```bash
docker run -d --name box ubuntu
docker ps -a                # STATUS: Exited (0)
docker logs box             # (empty)
```
It exited because `ubuntu`'s default command finishes immediately with no
foreground work to keep it alive — a container lives only as long as its main
process. Give it one: `docker run -d ubuntu sleep 3600`.
