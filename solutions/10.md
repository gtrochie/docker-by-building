# Module 10 — Solutions

**1. Watch health go healthy; read via inspect.**
```bash
docker run -d --name api -p 8000:8000 freelanceforge:prod
docker ps                                        # (health: starting) -> (healthy)
docker inspect --format '{{.State.Health.Status}}' api    # healthy
docker rm -f api
```

**2. Force an OOM kill (137).**
```bash
docker run -d --name hog --memory 64m python:3.12-slim \
  python -c "x=bytearray(500_000_000)"
docker ps -a                                     # Exited (137)
docker inspect --format '{{.State.OOMKilled}}' hog        # true
docker rm -f hog
```

**3. Diagnose a crash loop with logs only.**
```bash
docker run -d --restart always --name bad freelanceforge:prod \
  uvicorn nope:app --host 0.0.0.0 --port 8000
docker logs bad          # ModuleNotFoundError: No module named 'nope'
docker rm -f bad
```
The logs name the cause; fix the command rather than increasing retries.
