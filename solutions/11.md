# Module 11 — Solutions

**1. Tag and push :1.0 and :latest; shared layers skip re-upload.**
```bash
docker build -t freelanceforge:1.0 .
docker tag freelanceforge:1.0 youruser/freelanceforge:1.0
docker tag freelanceforge:1.0 youruser/freelanceforge:latest
docker login
docker push youruser/freelanceforge:1.0
docker push youruser/freelanceforge:latest    # base layers: "Layer already exists"
```

**2. Full capstone, data survives a db restart.**
```bash
docker compose up -d --build
curl localhost:8000/health
curl -X POST localhost:8000/quote -H 'Content-Type: application/json' -d '{"items":[1000,2500,500]}'
curl localhost:8000/db/ping                    # {"db":"ok",...}
docker compose restart db
curl localhost:8000/db/ping                    # still ok — dbdata volume persisted
docker compose down                             # no -v => data kept
```

**3. Quantify reclaimed space.**
```bash
docker system df                # note the "RECLAIMABLE" column
docker system prune             # remove stopped containers, dangling images, cache
docker system df                # compare before/after
```
