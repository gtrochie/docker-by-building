# Module 05 — Solutions

**1. Prove persistence across containers via a named volume.**
```bash
docker volume create keep
docker run --rm -v keep:/data alpine sh -c 'echo hi > /data/f'
docker run --rm -v keep:/data alpine cat /data/f      # hi  (survived new container)
```

**2. Bind-mount app/ with --reload; edit without rebuild.**
```bash
docker run --rm -p 8000:8000 -v "$(pwd)/app:/app" freelanceforge:dev \
  uvicorn main:app --host 0.0.0.0 --port 8000 --reload
# edit app/main.py on the host -> uvicorn reloads inside the container
```

**3. down vs down -v.**
```bash
docker compose up -d
docker compose down       ; docker volume ls | grep dbdata    # still listed
docker compose up -d
docker compose down -v    ; docker volume ls | grep dbdata    # gone
```
`-v` deletes named volumes; without it, data survives.
